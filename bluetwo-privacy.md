# BlueTwo Privacy Policy

Effective date: 2026-05-17

BlueTwo is an offline Android launcher. It is designed to provide a nostalgic
launcher experience using original assets and local device features.

## Data Collection

BlueTwo does not collect, sell, share, or transmit personal data to external
servers.

The app does not use:

- User accounts
- Analytics SDKs
- Advertising SDKs
- Tracking SDKs
- Remote telemetry
- External backend services

## Data Stored Locally

BlueTwo stores launcher preferences locally on the device, including:

- Selected language
- Visual and animation preferences
- Sound and haptic feedback preferences
- Nostalgia mode preference
- Notification badge preference
- Selected icon pack
- Preferred classic game emulator
- Local memory unit configuration
- Custom launcher icons selected by the user
- Recently launched app information used for the disc-style shortcut

This information remains on the device and is not sent to BlueTwo servers.

## Installed Apps

BlueTwo can read the list of launchable apps installed on the device so it can
display them inside the launcher. This list is used locally only.

BlueTwo can launch apps selected by the user through Android intents. It does
not modify app data.

## Notification Access

Notification badge support is optional. If enabled by the user, Android may ask
for notification listener access. BlueTwo uses notification data only to show
local launcher badges. Notification content is not uploaded, sold, or shared.

## Local Files and Classic Games

When the user creates a classic game memory unit, BlueTwo may ask the user to
select a local folder. The app scans only the user-selected folder to find
compatible local files and optional cover/icon images.

BlueTwo does not provide games, emulator files, BIOS files, copyrighted media,
or third-party assets. Users are responsible for using files they are legally
allowed to use.

## Custom Icons

Users can choose local image files to replace launcher icons. These images are
stored locally as launcher preferences and are not uploaded.

Supported user-facing image formats may include PNG, JPG/JPEG, WebP, and GIF,
depending on Android decoding support on the device.

## In-App Purchase

BlueTwo uses Google Play Billing through Flutter's official in-app purchase
plugin. Purchase processing, payment methods, receipts, refunds, and billing
account data are handled by Google Play.

BlueTwo stores only whether the premium unlock is active on the local device.
The app does not receive or store credit card numbers or payment credentials.

## In-App Review

BlueTwo may request a Google Play in-app review after a positive local action.
The review prompt and any submitted rating are handled by Google Play.

## Children

BlueTwo is not directed at children and does not knowingly collect personal data
from children.

## Changes

This policy may be updated if BlueTwo adds new functionality. Any future changes
should continue to describe what data is processed and why.

## Contact

Before publishing, add the developer support email configured in Google Play
Console.
